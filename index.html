The Tool Shed

An invite-only portal where a group of neighbours or friends list the tools they own, post photos of them, and book each other's tools on loan.

  • Invite only. Joining takes an email, a password you choose and a unique six-digit access code from an admin's code generator. There is no public sign-up.
  • Photos of every tool, checked by content rather than file name, and shown to members only.
  • Bookings that cannot collide. Request, approve or decline, mark returned, with a calendar where you tap a first and last day, and overdue flags.
  • Looks after its members. Roles, suspension, password reset links, optional email notifications.
  • On your phone too. An iOS and Android app (.NET MAUI) that shares the same accounts, tools and loans as the website.
  • Easy to host. ASP.NET Core 8, SQLite, one Docker Compose file with automatic HTTPS.

Try the interactive demo: the website and the phone app side by side on one set of sample data, running entirely in your browser.

The portal is a server application, so it runs on your own machine or host rather than on this page. The source, setup guide and deployment files are in the toolshed/ folder of this repository.
